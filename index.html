A tray app that saves the text and images you copy and opens a searchable panel with Ctrl+Shift+V. Uses Windows clipboard notifications (no polling), stores everything locally in SQLite, and passes 125 unit tests.

  • SQLite

  • Unit tests

A keyboard-first launcher: press Alt+Space, type, press Enter. Opens apps (including Microsoft Store apps), does quick maths, runs web searches with short prefixes, and supports bookmarks and custom aliases. All search logic lives in a separate, unit-tested core library with no Windows dependency.
