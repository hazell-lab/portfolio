PUT YOUR RESUME / CV HERE
=========================

1. Export your resume as a PDF.
2. Copy it into this folder.
3. Rename it exactly:  resume.pdf

So the final path is:

    portfolio/assets/resume/resume.pdf

The "Resume" button in the navigation bar and the "Download Resume"
button in the hero section already link to that exact file name,
so nothing else needs to change.

If you would rather use a different file name, open index.html and
search for:   assets/resume/resume.pdf
There are 2 places (navbar + hero). Replace both.

If you get a "file not found" error when you click the button, it
usually means:
  - the file is not inside this folder yet, or
  - the file name does not match (check for spaces / capital letters), or
  - the file extension is hidden in Windows and the real name is
    "resume.pdf.pdf"
